Privacy Policy

Application: jason-desktop-colabdrive
Last updated: 2026-11-10

Who uses this application

This application is a personal tool used exclusively by its owner (jasoncen96@gmail.com). It is not distributed to or intended for any other users.

What data is accessed

With the owner's consent, the application requests access to the owner's Google Drive (https://www.googleapis.com/auth/drive) so that rclone can read and write the owner's own files from the owner's Google Colab sessions.

How data is used and stored

  • Drive data is only transferred between the owner's Google Drive and the owner's own Google Colab virtual machines / computers.
  • OAuth tokens are stored only on the owner's own devices and Colab VMs.
  • No data is sold, shared with, or transferred to any third party.
  • No analytics, advertising, or tracking is performed.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
